# Project rules

- Never change the app version in `Cargo.toml`.
- Use English for all repository content, commits, and messages.
- English is the primary language for docs and code; `README_vn.md` is an optional secondary translation.
- Vietnamese is welcome in issues and pull requests, with full diacritics.
- Be concise and complete; no long examples, filler, or redundant explanations.
- Do not repeat existing information; edit or remove before adding.
- Prefer scripts and automation over long AI-dependent rules.
- Run `.\scripts\check.ps1` before committing; CI runs the same checks.
